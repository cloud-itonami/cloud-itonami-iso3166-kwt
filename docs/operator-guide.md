# Operator Guide

## First Deployment

1. Confirm the client's incorporation/legal-entity status is complete
   (route to `cloud-itonami-M6910` or local counsel first if not).
2. Register the client's intake: business type, target public function,
   prior filing history in Kuwait if any.
3. Run the advisor in read-only mode against the Central Agency for
   Public Tenders (CAPT, الجهاز المركزي للمناقصات العامة), the
   procurement authority for the State of Kuwait
   (https://www.capt.gov.kw/).
4. Compare the checklist against the client's current documentation
   (Commercial Registration via the Kuwait Business Center, CAPT
   tenderer/contractor/supplier registration, CAPT classification
   (تصنيف) certificate where applicable).
5. Determine whether the engagement is on the Article-31 default
   Kuwaiti-entity path (Commercial Register + CAPT registration) or
   the explicit foreign-bidder exception -- if foreign AND the tender
   is awarded, Article 87's National-Industry and Local-Contractor
   Preference applies and the client must be able to document BOTH a
   national-industry purchase commitment and a local-contractor
   subcontract commitment, each at least 30% (the law's own stated
   floor; a later Council of Ministers decision could change this,
   but no such decision was independently confirmed this session).
6. Enable gated filing-draft assistance once the Market-Entry Compliance
   Governor contract is trusted; actual submission always requires human
   sign-off.

## Minimum Production Controls

- client-owned data store for business/tax registration documents
- clear provenance (official portal/regulation citation) for every
  requirement surfaced
- approval workflow for any portal registration or filing submission
- named referral relationship with Kuwaiti-licensed counsel or a
  registered agent for anything beyond checklist/draft assistance
- monthly audit export

## Certification

Certified operators must prove data provenance, audit traceability, that
automated actions cannot bypass the Market-Entry Compliance Governor, and
a working referral relationship with Kuwaiti-licensed counsel or a
registered agent for whatever licensed representation the law of
Kuwait requires for actual public-procurement filings.
